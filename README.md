### 🖥️ Simulation
Contient le lien vers la simulation réalisée sur Tinkercad ainsi que les captures d'écran des différents états du système.

Tinkercad ne proposant pas de lecteur RFID MFRC522, un clavier matriciel a été utilisé afin de simuler l'identification par code PIN.
